# Public README template

Use this structure near the top of each public repository README.

```md
## Purpose

Describe what this repository does in one or two sentences.

## Status

State whether the repo is active, experimental, pre-mainnet, or production-facing.

## Scope

Explain what belongs in the repo and what does not.

## Governance relation

State whether the repo is maintained by Conxian Labs, how it relates to the protocol, and whether it is expected to support progressively decentralized governance after mainnet.

## Security

Do not disclose vulnerabilities publicly. Point to `SECURITY.md` and `security@conxian-labs.com`.

## Contact

Use:
- `info@conxian-labs.com`
- `support@conxian-labs.com`
- `security@conxian-labs.com`

## License

State the repository license.
```
