# Growth-Driver Metrics Specification (v1.0)

Derived from the "Conxian Unified Theory of Sovereign Enterprise".

## Core Variables

| Metric | Definition | Formula | Target |
| :--- | :--- | :--- | :--- |
| **C_R** | Cost of Reproduction (Structural Moat) | 0.35*TEE + 0.25*Clarity + 0.20*Compliance + 0.20*Stickiness | > 80 |
| **O_C** | Opportunity Cost (Founder manual critical-path load) | SUM(manual_hours) for critical-path workflows | < 10 hrs/wk |
| **V_X** | Execution Velocity | weighted_scope / median_cycle_time | Increasing |
| **A_S** | System Autonomy | automated_runs / total_runs | > 99.5% |
| **N_E** | Network Effects | AVG(participant_uplift_pct) | > 5% |

## Remote-First Growth Drivers

### 1. Qualified Conversations (QC)
- **Definition:** High-intent engagement with a potential partner or enterprise user.
- **Source:** CRM / Pilot Registry.
- **Target:** >= 5 per week.

### 2. Demos / Proof Assets (DPA)
- **Definition:** Successful demonstration of Gateway, Wallet, or SDK capabilities.
- **Source:** Demo Log.
- **Target:** >= 2 per week.

### 3. Pilot Proposals (PP)
- **Definition:** Formal proposal sent for a scoped pilot integration.
- **Source:** Commercial Registry.
- **Target:** >= 1 per week.
